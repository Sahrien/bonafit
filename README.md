# Bonafit

Studio product for Bonafit (personal training). Three independent apps — not a single install:

| Directory | What it is |
| --- | --- |
| `BonafitDesk/` | Admin studio and client portal (Angular) |
| `BonafitApi/` | JSON API and PostgreSQL (FastAPI) |
| `Webonafit/` | Public marketing site (Angular) |

Setup and conventions for automated agents: [AGENTS.md](AGENTS.md). Package-specific notes live in each directory’s `AGENTS.md`.
